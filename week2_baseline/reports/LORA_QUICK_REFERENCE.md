## 配置参数（关键代码）

```python
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=64,                      # LoRA 秩
    lora_alpha=128,            # 缩放系数 (通常 = 2×r)
    lora_dropout=0.05,         # Dropout 率
    target_modules=[           # 在这些层添加 LoRA
        "query", "key", "value", "dense"
    ]
)

model = get_peft_model(base_model, lora_config)
# 结果: 只训练 295K / 102M = 0.29% 参数
```

## LoRA 工作原理（简化版）

### 传统微调
```
更新所有参数 (102M)
显存: ████████████████ 16GB
```

### LoRA 微调
```
原始权重 W? (冻结 ??)
         +
LoRA 增量 ΔW = A × B (训练 ?)
         ↓
显存: ██████ 6GB
```

**公式**: `W_new = W? + (A × B) × (alpha/r)`

- A: 768 × 64
- B: 64 × 768
- 参数量: 98K << 589K

## 答辩问题准备

### Q: 为什么用 LoRA？
**A**: 单卡 GPU 显存有限（8GB），全微调需要 16GB，LoRA 只需 6GB，且训练速度提升 2.7 倍。

### Q: rank=64 怎么选的？
**A**: 
- 太小 (r<32): 表达能力不足
- 太大 (r>128): 过拟合 + 慢
- r=64: 平衡点（经验值 = 层数/2）

### Q: 性能损失能接受吗？
**A**: F1 从 0.35 降到 0.33，只损失 6%，但训练成本降低 63%，在资源受限场景下是最优解。
